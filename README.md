## 🏟️ [Vasudev AI Arena](https://arena.vasudevai.in)

**India's gamified builder community.**

A platform where builders can complete quests, contribute through bounties, earn XP, unlock badges, climb seasonal leaderboards and participate in community challenges.

```text
QUESTS       → complete challenges
BOUNTIES     → contribute & build
XP           → prove activity
BADGES       → unlock milestones
SEASONS      → compete & collaborate
REWARDS      → earn recognition
COMMUNITY    → build together
```

**Current direction:** Season-based builder ecosystem · challenges · rewards · open-source contribution.
